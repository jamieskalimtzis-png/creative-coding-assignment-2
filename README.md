# creative-coding-assignment-2

# Project Overview
My prototype is a song created using TunePad using the language of Python Code.
The overall goal of my prototype was to create a song that students can listen to whilst studying. Students like myself can find it hard to study while listening to music as it is often too upbeat and can cause you to lose focus. Some students listen to music to block out distractions however, the music can be the distraction. My goal is to create a song that limits distraction and affords focus for the listener. 

## How to Access the Song
To access the song that I have created you will need to have a computer that can access the TunePad website. It may also be helpful to have some headphones and possibly some study material to really see the intended gal.
